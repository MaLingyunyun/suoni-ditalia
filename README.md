# Suoni d'Italia

An Italian phonics trainer that follows the order Italian first-graders learn to read: 12 cities, one group of sounds each.

Each lesson has five steps: learn the rule, pick the word you hear (several voices), read aloud and compare, build the word from syllables, and a game (tombola, word fishing, sorting, stress clapping). Missed words come back in spaced review.

Open `index.html` in any modern browser. Audio uses the device's Italian text-to-speech voice; progress is saved in the browser.
